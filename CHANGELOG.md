# CraftLevel 1.0.3

## Added
- **Darkness Mark** — earned by fully clearing an Arena (1 mark per wave completed)
- **Death Merchant** villager profession (workstation: Arena Portal)
- Death Merchant trades paid with Darkness Marks:
  - Wither Skeleton Skull, Phantom Membrane, Echo Shard, Shulker Shell
  - Spawn Egg (random from a whitelist of vanilla mobs)
  - Elytra, Trident, Sculk Catalyst
  - Spawner (random from a whitelist of mob types)

## Fixed
- Mob Focus portrait broken with **Epic Fight** and shaders (**Oculus**)

## Changed
- Default configs now ship as JSON under `assets/craftlevel/defaults/` (copied to `config/craftlevel/` only if missing)
